# Aurora 更新

菜单：系统 → Aurora Theme Design → Aurora 更新。使用官方 GitHub Releases 的 APK，默认与固件在线升级相同的 `gh-proxy.com` 加速，可切换 GitHub 官方地址。原作者的签名 APK 源和光影猫系统源均保持不变。

检查更新仅读取作者的两个公开仓库。安装前只接受固定软件包名和 GitHub 官方发布路径，并核对 API 提供的文件大小与 SHA256；使用 APK 自带的版本比较阻止回退。安装必须在页面确认。作者的 GitHub Release 版本可能晚于签名源；这时页面会提示当前已经较新，不会降级。通过本地 APK 安装可能将 APK world 条目固定到该文件，后续仍可在此页面安装新版本。
