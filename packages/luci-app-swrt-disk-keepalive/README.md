# 硬盘保活

LuCI 插件，入口为 **系统 → 硬盘保活**。默认关闭，接入 USB 硬盘后选择目标、开启保活并保存即可。

- 默认每 60 秒直接读取 1 MiB，间隔支持 10～3600 秒，应小于硬盘盒的休眠时间。只读，不创建文件、不更改分区。
- 绕过 Linux 页缓存；每次移动读取位置。直接读取失败会显示错误，不用缓存读取伪装成功。
- 按 WWID 或有效序列号组合识别硬盘，不依赖 `/dev/sda` 名称。重插后继续，缺失、标识重复或系统磁盘不执行保活。
- 可关闭所选硬盘的 USB 自动挂起；停止服务或关闭保活时恢复原策略。不修改 USB 集线器、5G 模组或 UAS 驱动。
- 配置写入 UCI，运行计数和状态保存在 RAM，重启后清零。只有读取错误或恢复等事件写入系统日志。

这是一种空闲保活方法，不是修改硬盘盒固件。ASM1153E / Y1094 的实际休眠行为须接盘验证；保活不能保证解决供电、线材、接口或桥接芯片导致的掉盘，也不能防止所有硬盘固件内部的磁头停泊。

## 集成

将目录复制到 OpenWrt `package/`，在 `make menuconfig` 中选择 `LuCI → Applications → luci-app-swrt-disk-keepalive`。依赖由包管理器处理，支持 APK / IPK 对应的源码构建，不需要网络面板包。

内置后由系统包管理器管理。手动卸载前先执行 `/etc/init.d/swrt-disk-keepalive stop`，让服务恢复其修改过的 USB 自动挂起策略。

## 验证范围

测试覆盖稳定标识、重命名、重复标识、拔盘、只读权限、配置输入和无盘界面；使用临时 RAM 文件及独立 loop 设备验证直接读取增加块层读取计数，且文件哈希不变。loop 测试不能替代真实硬盘盒的长时间空闲测试。
